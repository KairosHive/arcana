# The exact combination this branch was tested against, on Windows 11 / Python 3.10.
#
#   uv venv
#   # GPU build first, from PyTorch's own index only:
#   uv pip install torch==2.9.1 torchvision==0.24.1 torchaudio==2.9.1 #       --index-url https://download.pytorch.org/whl/cu128
#   # then everything else from PyPI:
#   uv pip install -r requirements-lock.txt
#   uv pip install -e . --no-deps
#
# Two steps on purpose. uv will not mix indexes for a single package (it guards
# against dependency confusion), and the PyTorch index also serves stale copies
# of common packages like tqdm -- so pointing at it with --extra-index-url makes
# the whole resolve fail. Installing torch from it alone, first, avoids that.
#
# The pins below carry no +cu128 suffix, so "torch==2.9.1" is satisfied by the
# CUDA build above and by the plain CPU wheel on PyPI. For a CPU-only install --
# what a packaged app should ship -- just skip the first step.
